# لحظتنا | Lahzetna — النسخة الكاملة

موقع React + Vite عربي باتجاه RTL، يتضمن:
- صفحة رئيسية متجاوبة وهوية رومانسية.
- صفحة خطوات الاستخدام.
- أداة إنشاء هدية: عنوان، اسم المُرسل، اسم المستلم، المناسبة، التاريخ، الرسالة.
- رفع حتى 5 صور، اختيار ثيم من 4 ثيمات، ومعاينة مباشرة.
- صفحة هدية مستقلة على مسار `/g/:slug`.
- نسخ الرابط والمشاركة على واتساب.
- صفحة "هداياي" وإدارة الهدايا المحلية.
- تخزين محلي احتياطي عند عدم إعداد Supabase.
- دعم Supabase للحفظ الدائم وفتح الرابط من أجهزة مختلفة.

## ترقيات المزايا الجديدة

بعد تحديث الكود، افتح Supabase > SQL Editor وشغّل الملف `supabase/feature-upgrades.sql` مرة واحدة. هذا ينشئ جداول ردود المستلمين ومفاتيح إدارة الردود وإحصائيات التحويل، ويوقف القراءة/الإنشاء المباشر للهدايا من مفتاح المتصفح حتى تمر عبر API للتحقق من موعد الفتح والانتهاء. لا تغيّر إعدادات الدفع الحالية.

## تشغيل المشروع محليًا

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run dev
```

## تفعيل قاعدة البيانات (مهم للرابط العام)

1. أنشئ مشروعًا في https://supabase.com/
2. افتح SQL Editor في مشروع Supabase.
3. انسخ وشغّل الملف `supabase/schema.sql`.
4. من Project Settings > API انسخ Project URL ومفتاح `anon` / publishable key.
5. انسخ `.env.example` إلى ملف اسمه `.env` في جذر المشروع.
6. ضع القيم:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
```

7. أعد تشغيل `npm run dev` أو أعد البناء والنشر.

**لا تضع service_role key أو أي مفتاح سري داخل الواجهة الأمامية.**

### حدود النسخة الحالية
- إذا لم تُضبط Supabase، فالهدايا محفوظة في LocalStorage على نفس المتصفح والجهاز فقط؛ الرابط لا يضمن فتح الهدية على جهاز آخر.
- الصور تُخزن حاليًا داخل سجل الهدية كـ data URLs. هذا مناسب لتجربة أولية وصور قليلة، لكنه ليس الخيار الأفضل للتوسع. قبل إطلاق تجاري واسع، انقل الصور إلى Supabase Storage، وضع حدًا لحجم الملفات، وأضف مصادقة وقيودًا لمنع الإساءة.
- رابط الهدية غير قابل للتخمين بسهولة لكنه ليس نظام خصوصية أو مصادقة كاملًا. أي شخص يملك الرابط يستطيع فتح الهدية.
- مشاركة واتساب تفتح رابط مشاركة برسالة جاهزة؛ لا ترسل الرسالة تلقائيًا.
- زر الموسيقى مجرد لمسة تصميمية ولا يشغّل ملفًا صوتيًا.
- هذه نسخة جديدة مستوحاة من اسم وفكرة "لحظتنا"، وليست نسخة مطابقة حرفيًا من الموقع المنشور السابق لأن ملفات المصدر الأصلية لم تكن متاحة.

## النشر

### Vercel
1. ارفع المجلد إلى GitHub من جهازك أو محرر الأكواد.
2. استورد المستودع في Vercel.
3. أضف متغيري البيئة `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.
4. Deploy.

### Bolt
استورد ملفات المشروع إلى مشروع جديد إن كانت خاصية الاستيراد متاحة في حسابك، ثم أضف متغيرات البيئة الخاصة بـ Supabase. قد تختلف أسماء الأزرار حسب واجهة Bolt وخطتك.

## هيكل الملفات

- `src/main.jsx` واجهة الموقع وسلوك إنشاء/عرض الهدايا.
- `src/styles.css` تصميم متجاوب.
- `supabase/schema.sql` جداول وسياسات قاعدة البيانات.
- `.env.example` مثال متغيرات البيئة.


## ميزات إضافية
- خط زمني للذكريات: حتى 6 محطات بتاريخ وعنوان ووصف، وتظهر داخل الهدية.
- فتح مفاجأة بموعد محدد مع عدّ تنازلي مرئي قبل موعدها؛ هذا عرض واجهة وليس قفل وصول أمنيًا.
- اقتراحات رسائل جاهزة موسعة دون توليد ذكاء اصطناعي.
- تصدير نتائج بحث لوحة الإدارة إلى CSV.
- إشعارات تيليجرام عند وصول طلب الدفع، وبعد قبول الطلب أو رفضه إذا كانت متغيرات تيليجرام مضبوطة.
- دعم التثبيت كتطبيق ويب (PWA) وأساسيات العمل دون اتصال للواجهة.
- ضغط الصور عند اختيارها لتقليل الحجم قبل إرسال الطلب.
- بيانات مشاركة اجتماعية محسنة لروابط الموقع.
- 8 ثيمات لونية للمناسبات المختلفة.
- مناسبات إضافية: خطوبة، زواج، اشتياق، صداقة، وعيد الأم.
- مساعد اقتراحات رسائل قابل للتعديل (قوالب جاهزة، وليس توليدًا عبر نموذج ذكاء اصطناعي).
- إمكانية حفظ نص الهدية كملف TXT.
- راجع ملاحظات الأمان في `supabase/schema.sql` قبل الاستخدام التجاري.

## متغيرات البيئة في Vercel
أضف:
- `VITE_SUPABASE_URL`: رابط مشروع Supabase.
- `VITE_SUPABASE_ANON_KEY`: المفتاح العام (anon/publishable) فقط.
بعد تشغيل SQL في Supabase، أعد نشر المشروع من Vercel.
