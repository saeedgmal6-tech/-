# لحظتنا

موقع لإنشاء هدايا رقمية ومشاركتها برابط خاص.

## التخزين
- تُحفظ الهدايا والملفات في Vercel Blob.
- يحتاج المشروع إلى ربط Blob Store باسم `lahzetna-gifts` على Vercel.
- متغير البيئة المطلوب: `BLOB_READ_WRITE_TOKEN`، ويُضاف تلقائيًا عند ربط مساحة التخزين بالمشروع.
- لا يعتمد الموقع على Supabase.

## التشغيل المحلي
```bash
npm install
npm run dev
```

## النشر
اربط مستودع GitHub بمشروع Vercel، وسيتم النشر تلقائيًا عند تحديث فرع `main`.

## حدود الاستخدام
تخضع مساحة التخزين والرفع لحدود وخطة Vercel Blob وVercel Functions. لا تضع مفاتيح سرية داخل ملفات الواجهة الأمامية.
